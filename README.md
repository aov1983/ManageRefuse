# Refund – Менеджер цифровых подписок

Android-приложение для отслеживания платных подписок, получения напоминаний о списаниях и экономии бюджета.

## Описание

**Платформа:** Android 8+ (API 26)  
**Целевой магазин:** RuStore  
**Тип приложения:** Нативное, локальное хранилище, работа без интернета

## Функциональность

- 📱 Онбординг при первом запуске
- ➕ Управление подписками (CRUD)
- 🔔 Напоминания о предстоящих списаниях
- 📖 Инструкции по отмене подписок
- 📊 Дашборд со статистикой трат и экономии
- 🤝 Партнёрские предложения
- 📤 Экспорт/импорт данных в CSV
- 🌙 Тёмная тема с поддержкой Material You

## Структура проекта

```
app/
├── data/           # Работа с данными (Room, Retrofit, Repository)
├── domain/         # Бизнес-логика (Models, UseCases)
├── presentation/   # UI (Activities, Fragments, ViewModels)
├── di/            # Dependency Injection (Hilt)
└── utils/         # Вспомогательные классы
```

## Технологии

- **Язык:** Kotlin
- **Архитектура:** Clean Architecture + MVVM
- **DI:** Dagger Hilt
- **База данных:** Room
- **Сеть:** Retrofit + OkHttp + Moshi
- **Асинхронность:** Kotlin Coroutines + Flow
- **Уведомления:** WorkManager
- **UI:** Material Design 3, ViewBinding

## Сборка и запуск

1. Откройте проект в Android Studio
2. Синхронизируйте Gradle
3. Запустите на эмуляторе или устройстве (Android 8+)
